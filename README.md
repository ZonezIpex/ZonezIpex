## About Me

브랜드와 서비스의 핵심을  
**전달력 있는 콘텐츠와 비주얼로 풀어내는 콘텐츠 마케터**입니다.

로고, 포스터, 소개자료, 웹 화면 등  
다양한 형식으로 메시지를 더 직관적으로 보이게 만드는 작업을 합니다.

기존의 웹 퍼블리싱 경험은  
현재 **화면 구조 이해, 랜딩 흐름 파악, 개발 협업 커뮤니케이션**의 강점으로 이어지고 있습니다.

## Focus

- **Content Planning**  
  목적과 타겟에 맞는 콘텐츠 주제와 메시지를 기획합니다.

- **Visual Branding**  
  로고, 포스터, 썸네일, 소개형 콘텐츠를 제작합니다.

- **Visual Communication**  
  복잡한 정보도 이해하기 쉬운 형태로 정리합니다.

- **Collaboration**  
  기획, 디자인, 개발 흐름을 함께 이해하며 협업합니다.
