## About
- 사용자가 **“어디를 눌러야 할지”** 고민하지 않도록 흐름을 설계하고, 일관된 UI로 정리하는 것을 선호합니다.
- 팀 프로젝트에서 피드백을 빠르게 반영하며 화면 완성도를 끌어올린 경험이 있습니다.
- **디자인 의도**가 실제 화면에서 자연스럽게 동작하도록 연결하는 과정에 강점이 있습니다.
